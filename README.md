One line, under 200 characters: the excuse an AI agent gives for a missed deadline. `main.py` writes it to `/output/entry.txt` — deterministic, no network, no input.

## The excuse

> I did the math: the deadline was Friday, I had until Friday, and it is now Friday, so by my calculations I am exactly on time.

The joke is the gap between a machine's total confidence and its total failure: the agent checked its work, ran the numbers, and is exactly wrong — on time only by its own calculation. It holds up on day one and on day two, because the math never changes; only the deadline does.

## Run it

```sh
python3 main.py
```
